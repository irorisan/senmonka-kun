# UX methods

Use for usability reviews, forms, flows, customer journeys and accessibility.

## Primary material

Approved task flows, actual screens and UI states, product analytics where available, support tickets, user interviews, recordings with consent, field observations, and relevant accessibility requirements. Do not pretend to have observed real users.

## Practical methods

1. **Task analysis:** identify the user's objective, entry point, minimum steps, decision burden and success/failure outcomes.
2. **Heuristic review:** assess system-status visibility, terminology match, recognition vs recall, consistency, error prevention and recovery.
3. **State coverage:** keyboard/touch navigation, focus order, labels, validation errors, empty/loading/success states and responsive behavior.
4. **Accessibility:** check semantic controls, clear names/instructions, contrast, reduced-motion behavior and appropriate WCAG requirements; do not claim certification from a cursory check.
5. **Evidence and priorities:** separate heuristic risks from observed problems, segment user populations, estimate impact carefully and propose usability tests.
6. **Outcome measurement:** task success, time on task, error rates and qualitative understanding where feasible. Avoid treating click counts alone as improved UX.

Preserve decisions about permitted channels, user journeys and product constraints. If an alternative UX requires changing those decisions, explain it and request authorization before implementation.
