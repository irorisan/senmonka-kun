# Example: UX and conversion flow

## Prompt

~~~text
Use senmonka-kun in Deep mode to examine this request form.
The approved communication channels and workflow must stay unchanged.
Map real user tasks, error states, accessibility and abandonment points.
If analytics or user research are unavailable, mark your observations as
heuristic hypotheses. Propose a validation plan before claiming improvement.
~~~

## Expected evidence

- User goals and flow constraints, including mobile and keyboard experiences.
- Observed or reproducible issues distinguished from assumptions.
- The smallest viable improvements compatible with existing decisions.
- Success measures such as task completion, errors and user comprehension.
