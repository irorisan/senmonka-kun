# Example: evidence-based documentation

## Prompt

~~~text
Use senmonka-kun in Standard mode to draft a maintenance guide using the
approved procedure and service records. Keep approved limits and steps unchanged.
Check tables and units against sources, distinguish missing torque or interval
values from facts, and make the guide readable to a new technician.
Do not issue, publish or claim the draft is approved.
~~~

## Expected evidence

- Intended audience, document status, revision and controlling sources.
- Traceable factual statements and numerical values; unverified items flagged.
- Logical instructions, visual readability and export checks when available.
- Clear review/sign-off requirements; no invented instructions or approval.
